# ダイナマリサ3D HD MOD

黄昏フロンティアの TPS「ダイナマリサ3D」(2011年)を、現代の PC で快適に遊ぶための非公式 MOD です。

- 720p 固定だった描画を、モニターの解像度(4K まで)で描く
- 遠景のぼかしをなくして、くっきり表示する
- 照準の「後半にかかるブレーキ」を外したうえで、滑らかに動作するようにする
- フレーム補間で、60fps 固定のゲームを 60fps 超で滑らかに表示する(実験的)

ゲーム本体やデータファイルは一切書き換えません。ゲームフォルダに置くファイルを消せば、完全に元に戻ります。

**対応バージョン**: 初版、公式パッチ v1.02 適用版(推奨)

> [!IMPORTANT]
> これはファンによる非公式 MOD です。黄昏フロンティア様・上海アリス幻樂団様とは一切関係ありません。
> このリポジトリにゲーム本体は含まれていません。遊ぶにはゲームを正規に入手してください。

## 機能

すべての機能は、付属の設定ツール `dynamarisa_hd_config.exe` で選べます。

| 機能 | 内容 |
| --- | --- |
| 内部描画解像度 | 1280×720 固定の描画を、1600×900〜3840×2160(既定はモニターの解像度)で行う |
| スーパーサンプリング | さらに 1.5倍 / 2倍の解像度で描いて縮小し、ギザギザを減らす |
| ウィンドウサイズ | ウィンドウモードを好きな大きさにする |
| 影の解像度 | 影マップを 1024 → 2048 / 4096 にする |
| 異方性フィルタ | 斜めから見た床や壁のテクスチャのぼやけを抑える |
| 遠景ぼかし | ゲーム本来の被写界深度(遠くほどぼかす処理)をオフ / 弱め / オリジナルから選ぶ |
| 照準の慣性 | 素早く振ると後半に遅れて追いつく照準の挙動をなくす |
| マウス照準の細かさ | 1カウントあたり約0.23度と粗い照準を、1/2〜1/4 に細かくする |
| フレームレート上限 | モニター同期 / 60 / 120 / 144 / 165 / 240 / 無制限 |
| フレーム補間(実験的) | 60Hz で動くゲームの合間を補間して、上限いっぱいまで滑らかに描く |
| 全画面化の位置補正 | 元のゲームで Alt+Enter 全画面時に画面上端が欠ける不具合を直す |
| マウスの反応範囲 | 大きなウィンドウ・全画面で、画面全体でマウスが反応するようにする |

各項目の詳しい説明は [dist/README_HDMOD.txt](dist/README_HDMOD.txt) を参照してください。

## 導入方法

1. [Releases](../../releases) から `DynamarisaHD_v*.zip` をダウンロードします。
   公式パッチ(v1.02)を当てる場合は、MOD を入れる前でも後でも構いません。
2. zip の中身を、ゲームのフォルダ(`dynamarisa.exe` があるフォルダ)にそのままコピーします。
3. `dynamarisa_hd_config.exe` を起動し、設定を選んで「保存して起動」を押します。
   普段どおり `dynamarisa.exe` から起動しても MOD は有効です。

### 元に戻すには

ゲームフォルダの `d3d9.dll` を削除してください。`d3d9mod.ini`・`dynamarisa_hd_config.exe`・`README_HDMOD.txt` も不要になります。

## しくみ

MOD の技術的なしくみは、かなりゆるめに [docs/HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md) で解説しています。

要点は次のとおりです。

- ゲームが読み込む DirectX 9 の部品 `d3d9.dll` と同じ名前の DLL をゲームフォルダに置き、ゲームと本物の DirectX の間で描画命令を中継・手直しする(DLL プロキシ)。
- 描画用のキャンバス(レンダーターゲット)を大きなものにすり替え、座標を倍率に合わせて直す。ゲームにはサイズを元の 1280×720 で答えるので、ゲームからは何も変わっていないように見える。
- ウィンドウやマウスの処理は、Windows の機能の呼び出し先(IAT)を差し替えて手直しする。
- 照準のブレーキは、ゲーム本体の機械語を解析し、起動時にメモリ上で分岐を書き換えて外す。

## ビルド方法

必要なもの:

- Windows 10 / 11
- Visual Studio 2022(「C++ によるデスクトップ開発」ワークロード。x86 用のコンパイラーと Windows SDK を含む)
- Python 3(ラッパーを再生成する場合のみ)

```bat
build.bat
```

`out\` に `d3d9.dll` と `dynamarisa_hd_config.exe` ができます。配布用の zip は次で作れます。

```powershell
powershell -ExecutionPolicy Bypass -File scripts\make_release.ps1 -Version 1.0.0
```

`release\DynamarisaHD_v1.0.0.zip` ができます。

`build.bat` は Visual Studio 2022 Community の既定のインストール先を前提にしています。別の場所やエディションの場合は、`build.bat` 内の `vcvars32.bat` のパスを書き換えてください。

## フォルダ構成

| パス | 内容 |
| --- | --- |
| `src/main.cpp` | MOD 本体(`d3d9.dll`) |
| `src/config.cpp` | 設定ツール(`dynamarisa_hd_config.exe`) |
| `src/wrap_gen.h` | DirectX 9 の命令をそのまま中継する部分(`tools/gen_wrappers.py` で自動生成) |
| `src/forward.h`, `src/d3d9.def` | MOD が使わない `d3d9.dll` の機能を本物へ転送する設定 |
| `src/probe.cpp` | 調査用: ゲームの描画命令をログに記録するだけの `d3d9.dll`(`build.bat probe` でビルド) |
| `dist/` | 配布 zip に入れる設定ファイルと説明書 |
| `docs/HOW_IT_WORKS.md` | 技術解説 |
| `scripts/make_release.ps1` | 配布 zip の作成 |
| `tools/gen_wrappers.py` | Windows SDK の `d3d9.h` から `src/wrap_gen.h` を生成 |
| `tools/research/` | 調査用ツール(下記) |
| `tools/test/` | 動作確認用のスクリプト(ゲームを自動操作するので、リポジトリをゲームフォルダの中に置いて使う) |

### 調査用ツール

| ツール | 内容 |
| --- | --- |
| `tools/research/datx.py` | ゲームのデータアーカイブ(`dynamarisa00.dat` など)の一覧表示・展開・作成 |
| `tools/research/sqdis.py` | ゲームのスクリプト(Squirrel 2 のコンパイル済みファイル `.cv4`)の逆アセンブラ |
| `tools/research/loadtest.cpp` | DLL 単体の読み込みテスト |

展開したゲームデータには著作権があります。展開したデータそのものを公開・再配布しないでください。
